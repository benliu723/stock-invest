# Analysis

本目录用于存放正式分析过程。

这里记录的不是最终压缩后的结论，而是从观察到推理、再到判断的完整分析链条。

## 用途

- 展开一次正式的长期状态分析
- 记录“为什么更支持这个状态，而不是另外两种”
- 为最终写入 `cases/` 的结论提供过程支撑

## 使用方式

每次分析建议按以下顺序展开：

1. 记录当前重要观察
2. 说明这些观察分别意味着什么
3. 推导长期更可能处于哪一种状态
4. 提炼为 3 条以内核心理由
5. 最后压缩为一句话总结

## 与其他目录的区别

- `notes/` 是原料区，放零散记录
- `analysis/` 是推理区，放正式分析过程
- `cases/` 是结果区，放最终结论
