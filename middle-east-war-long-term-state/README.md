# 中东战争长期状态分析

一句话版本：

这是一个用于判断中东战争长期更可能处于升级、僵持还是缓和状态的结构化分析框架，而不是精确预测模型。

## 项目目标

本项目关注的不是短期新闻波动，也不是精确预测某一天会发生什么，而是判断中东战争在较长时间尺度上，更可能处于哪一种阶段性稳定状态，并说明支撑这一判断的核心原因。

## 核心问题

当前中东战争长期更可能处于以下哪一种状态：

- 升级
- 僵持
- 缓和

## 基本假设

战争长期状态，通常由主要参与方在核心诉求、阶段性优先级和现实约束共同作用下，经过持续博弈后，形成某种阶段性稳定形态。

## 输出形式

每次分析只输出四项内容：

1. 长期状态判断
2. 低 / 中 / 较高 的置信度
3. 3 条以内的核心理由
4. 一句话总结

## 分析原则

1. 先判断长期状态，再解释核心原因。
2. 只做大致推断，不做精确预测。
3. 不使用权重、分数、精确概率来伪装确定性。
4. 重点关注主要参与方的核心诉求、阶段性优先级和现实约束。
5. 结论保持克制，只给出有限置信的长期基线判断。

## 非目标

本项目不追求：

- 自动生成客观权重
- 精确概率预测
- 严格意义上的长期均衡求解
- 用模型结果替代独立判断

## 目录分工

- `notes/`
  - 放原始想法、零散记录和未成型判断
- `analysis/`
  - 放正式分析过程，承接“观察 -> 推理 -> 判断”
- `cases/`
  - 放最终结果，保留最简结论

## 一句话定义

这是一个用于生成中东战争长期基线判断的结构化分析框架，而不是一个精确预测系统。
