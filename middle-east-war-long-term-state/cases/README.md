# Cases

本目录用于存放中东战争长期状态分析的示例与个案。

## 说明

当前提供 3 个基础样例，分别对应三种长期状态：

- `example.md`
  - 示例：长期更可能处于 `僵持`
- `escalation.md`
  - 示例：长期更可能处于 `升级`
- `deescalation.md`
  - 示例：长期更可能处于 `缓和`

这些文件的作用不是给出固定答案，而是展示同一套分析框架在不同状态下应如何表达结论与理由。

## 使用方式

写新的长期分析时，可以参考这些样例的结构：

1. 先给出长期状态判断
2. 再给出置信度
3. 再写 3 条以内的核心理由
4. 最后用一句话总结

## 注意

- 样例用于展示分析格式，不代表对未来的确定性预测
- 所有结论都应理解为大致推断，而不是精确判断
- 重点是说明“为什么更像这个状态”，而不是追求精确量化
