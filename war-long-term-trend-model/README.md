# 战争长期趋势模型

## 核心假设

`战争长期趋势，是各参与方在动态权重和现实约束下，围绕核心诉求持续博弈后形成的均衡方向。`

这个假设的基础是：

1. 战争是多方持续互动的结果，不是随机事件堆积。
2. 战争很难长期停留在明显违背关键参与方底线的位置，因为强势参与方会持续纠偏。
3. 长期战争更常停留在次优均衡，而不是最优解。
4. 各方诉求并不等权，且权重会变化；长期趋势由诉求、力量、约束与阶段优先级共同决定。

## 项目目标

本项目不用于复盘每日新闻，也不用于预测某一天是否开战，而是从多方博弈角度理解战争长期会向哪个方向演化。

它服务于投资，目标是帮助形成对战争大趋势的认同，从而辅助判断未来更值得关注的投资方向。

## 与 `中东局势分析` skill 的区别

`中东局势分析` skill 关注“现在”，核心任务是从新闻、事实、市场等短期信息中提炼当前战争更偏向哪个方向，减少信息噪音，逼近当前更真实的状态。

当前模型关注“未来”，核心任务是从主要参与方的诉求、权重、现实约束与持续博弈出发，判断战争长期将如何演化。

一句话总结：

`中东局势分析模型 skill 帮我看清现在，当前模型帮我理解未来。`

## 希望得到的结果

模型最终希望产出的，是对战争长期趋势的结构化判断，包括：

- 长期主趋势
- 长期形态
- 趋势形成原因
- 改判条件

## 迭代路线

- `v1：静态核心框架`
  只考虑美国、以色列、伊朗；诉求静态，参与方权重静态；验证模型能否产出合理的长期趋势判断。

- `v2：引入动态权重`
  在 v1 基础上引入动态诉求权重和动态参与方权重，观察外部变量变化时，各方优先级和影响力能否合理变化。

- `v3：加入黑天鹅扰动`
  在动态权重基础上加入低概率高冲击事件，解释长期趋势为何会出现跳变而非平滑延续。

- `v4：扩展参与方`
  将模型扩展到更真实的多方博弈环境，逐步加入欧洲、俄罗斯、中国、日本、韩国等参与方。

- `v5：验证与展示`
  对模型进行回测、比较与可视化，验证解释力并提升结果可读性。
